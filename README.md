# plugsql

Plug encode/decode helpers for sql payloads in pipelines.

**Site:** https://theworker02.github.io/plugsql/

## Install / run

```bash
git clone https://github.com/theworker02/plugsql.git
cd plugsql
node src/cli.js
node --test
```
